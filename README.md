# Customer Churn Analysis & Prediction

An end-to-end data analytics and machine learning project focused on understanding customer attrition, identifying key churn drivers, and building predictive models to improve retention strategies.

---

## 📌 Business Overview

Customer churn is a critical metric for subscription and service-based businesses. Retaining existing customers is significantly more cost-effective than acquiring new ones.

This project performs exploratory data analysis (EDA) to uncover operational drivers behind customer attrition and builds predictive models to identify high-risk customers before they churn.

### **Key Objectives**
- **Identify Risk Factors:** Analyze demographic, behavioral, and contractual features influencing churn.
- **Predict Attrition:** Train and evaluate machine learning models to classify customer churn risk.
- **Provide Actionable Insights:** Enable proactive business interventions and retention campaigns.

---

## 🛠️ Tech Stack & Tools

- **Language:** Python
- **Data Analysis & Manipulation:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Machine Learning & Modeling:** Scikit-Learn (Logistic Regression, Decision Trees, Random Forest, XGBoost)
- **Environment:** Jupyter Notebook / VS Code
